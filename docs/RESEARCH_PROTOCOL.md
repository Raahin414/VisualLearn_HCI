# E1 visual-density study - draft protocol

## Purpose and scope

Compare comprehension, immediate recall, one-hour retention and reported learning experience across three visual-density presentations of the same Water Cycle lesson. This is one between-participant study; modality, chunking, animation, video and adaptive studies are outside the current project.

## Conditions and controls

Low: canonical text/narration with one essential whole-cycle diagram. Medium: same essentials with supportive callouts and two additional process illustrations. High: same essentials with four process illustrations, repeated process labels and decorative details. No extra factual propositions, audio tracks, quiz hints or navigation privileges are added. All five chapters, essential diagram meaning, text, audio bytes, controls, objective tests and written rubrics remain shared.

The manipulation is a supportive/decorative density package. Viewport, scrolling burden, salience and visual relevance cannot be independently identified from this comparison. Source parity does not establish educational validity. Final screenshots/manipulation measurements and educator review are required before freezing a real trial.

## Participant sequence

Reviewed consent/F0 -> baseline A -> server age-stratified balanced assignment with random ties -> five chapters in the saved density -> written recall/scenario then objective B -> F3 -> waiting -> C at +60 minutes from server lesson completion -> F5 -> finished. Secure return links allow leaving the browser. The draft one-hour grace is 30 minutes; due/deadline boundaries are inclusive and later submissions are rejected. The final window/late policy requires approval.

Only adults 18-30 can enroll. Proposed minor age bands remain blocked until an independently verified guardian/assent process is approved and implemented. Language fields are self-report; the lesson remains English. No student chooses or changes a research density.

Optional seven-day D/F6 remains disabled. Inclusion is currently configured per experiment and frozen at enrollment; optional consent wording/process, exact grace window, C/F5-before-D sequence and feedback timing need separate review. There is no invented participant opt-in checkbox or default live seven-day grace.

## Measurements and analysis

A/B/C have eight objective items: four recall MCQs, ordering, labeling, conceptual and transfer. One point per item; ordering accepts rotations and labeling/ordering are all-or-nothing. B/C add written recall (10-point rubric) and scenario (4-point rubric), independently rated blind to condition with adjudication. D is a distinct optional bank. Matching blueprints do not prove equal difficulty.

Draft primary outcome: immediate percentage correct adjusted for baseline. Register one endpoint, sample plan, model, confidence intervals, device/language/accommodation policy and missingness/sensitivity handling before collection. F3 experience and 1-9 effort items remain separate; F5 records interim topic review. Response-review heuristics are draft review prompts, not validated scales, diagnoses, exclusions or adaptation.

Navigation, audio and visibility events are behavior proxies, not attention measurements. Missingness is not zero. Withdrawn data is excluded from exports. Different frozen versions remain separate cohorts.
