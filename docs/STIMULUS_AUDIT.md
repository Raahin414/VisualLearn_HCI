# E1 visual-density stimulus audit - draft

Current scope: one lesson, three additive visual densities. Presentation density-v6-e1-draft; shared source e1-v8-draft. Canonical lesson JSON, objectives, five WAVs and question/rubric objects remain unchanged.

| Material | Low | Medium | High |
|---|---|---|---|
| Identical canonical text, narration and controls | Yes | Yes | Yes |
| Same 800x470 essential whole-cycle diagram | Yes | Yes | Yes |
| Existing supporting callouts/arrows | No | Yes | Yes |
| Additional process illustrations | 0 | 2: evaporation, condensation | 4: evaporation, condensation, precipitation, collection |
| Existing in-diagram decorative layer | No | No | Yes |
| Additional decorative accent strip | No | No | Yes; 12 nonsemantic dots |

DensityVisuals is shared by public preview and assigned participant lessons. densityConfig centralizes the number of supporting panels and layer flags. All labels and illustrations repeat processes taught in the canonical lesson; no new test-relevant propositions are introduced. Essential diagram, transcript, key idea, audio source and core controls remain the same. Shared narration controls precede the variable visual material, keeping playback access in the same location for every density. Additional panels change scrolling length; this is an explicit manipulation limitation. Student research screens never show a density selector; previews do.

At small viewports supporting panels wrap; all controls remain accessible. High density must not obscure content or deliberately fail contrast/accessibility. No added animation. Changes create a new draft freeze, so existing incompatible sessions remain saved but fail closed rather than adopting a new stimulus silently.

The owner's reference image defines the conceptual low/medium/high progression, not a requirement to copy its dark palette. Keep the established academic cream/teal UI. Exact object area, edge density, salience and independent manipulation checks remain unmeasured. More graphics also alter scrolling and repeated-label exposure; density and relevance effects are not separately identified. Review all segments and viewport policy before a human trial.

Screenshots for the new matrix are generated under docs/screenshots/e1/. Actual validation results are recorded in QA.md. Historical captures are evidence of older draft presentations, not the current layout.
